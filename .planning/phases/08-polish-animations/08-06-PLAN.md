### 2. shouldRepaint в radar chart CustomPainter

Найти CustomPainter для radar chart в `character_page.dart`. Исправить:

```dart
@override
bool shouldRepaint(covariant CustomPainter old) {
  if (old is! _RadarPainter) return true;
  return old.stats != stats;  // перерисовываем только если данные изменились
}
```

### 3. const виджеты в dashboard

Найти и добавить `const` ко всем статичным виджетам:
- `const SizedBox(height: X)`, `const SizedBox(width: X)`
- `const Divider()`
- `const SizedBox.shrink()`
- Статичные `Text` без динамики
