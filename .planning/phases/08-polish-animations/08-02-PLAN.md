## Steps

### 1. Добавить звуковые файлы в assets/sounds/

Скачать или создать 3 коротких звука (< 1 сек, WAV или MP3):
- `levl/assets/sounds/quest_complete.mp3` — короткий позитивный тон
- `levl/assets/sounds/level_up.mp3` — более насыщенный звук достижения
- `levl/assets/sounds/ui_tap.mp3` — лёгкий клик

> Временно можно использовать любые MP3 для тестирования.
> Бесплатные источники: freesound.org, mixkit.co/free-sound-effects/

### 2. Создать AudioService

Создать файл `levl/lib/core/audio/audio_service.dart`:

```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:just_audio/just_audio.dart';
import 'package:riverpod_annotation/riverpod_annotation.dart';

part 'audio_service.g.dart';

class AudioService {
  final AudioPlayer _player = AudioPlayer();

  Future<void> playQuestComplete() => _play('assets/sounds/quest_complete.mp3');
  Future<void> playLevelUp() => _play('assets/sounds/level_up.mp3');
  Future<void> playUiTap() => _play('assets/sounds/ui_tap.mp3');

  Future<void> _play(String asset) async {
    try {
      await _player.setAsset(asset);
      await _player.seek(Duration.zero);
      await _player.play();
    } catch (_) {
      // Звук не критичен — не падаем из-за аудио-ошибок
    }
  }

  void dispose() => _player.dispose();
}

@Riverpod(keepAlive: true)
AudioService audioService(Ref ref) {
  final service = AudioService();
  ref.onDispose(service.dispose);
  return service;
}
```

### 3. Запустить кодогенерацию

```bash
cd levl
dart run build_runner build --delete-conflicting-outputs
```

Убедиться что создался `levl/lib/core/audio/audio_service.g.dart`.

### 4. Подключить звук в quest completion

В `levl/lib/features/dashboard/presentation/screens/dashboard_page.dart`:

Добавить импорт:
```dart
import 'package:levl/core/audio/audio_service.dart';
```

Найти место где вызывается `onComplete()` в виджете `_QuestCard` (через `_MainQuestCard`) — там где `HapticFeedback.mediumImpact()`. Передать `ref` в виджет или использовать `Consumer`.

Изменить логику onComplete в `DashboardPage` (метод `_buildQuestSection` или где создаётся `QuestCard`). Добавить воспроизведение звука:

```dart
onComplete: () async {
  ref.read(audioServiceProvider).playQuestComplete();
  ref.read(questNotifierProvider.notifier).completeQuest(quest.id);
},
```

> Звук запускается fire-and-forget (не awaited) чтобы не блокировать UI.
