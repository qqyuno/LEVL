# Plan 08-01 — Dependencies & Assets Setup

**Phase:** 8 — Polish & Animations
**Wave:** 1
**Depends on:** —
**Goal:** Подключить rive, lottie, just_audio в pubspec и создать папку assets/sounds/.

## Context

- `rive` и `lottie` закомментированы в pubspec.yaml (строки 31-32)
- `just_audio` отсутствует — нужно добавить
- `assets/sounds/` не существует — нужно создать и зарегистрировать в pubspec

## Steps

### 1. Обновить pubspec.yaml

Раскомментировать и добавить зависимости в секцию `dependencies`:

```yaml
  # Animations
  rive: ^0.13.0
  lottie: ^3.1.0

  # Audio
  just_audio: ^0.9.40
```

Добавить в секцию `flutter.assets`:
```yaml
    - assets/sounds/
```

### 2. Создать папку assets/sounds/

```bash
mkdir -p levl/assets/sounds
```

Добавить placeholder файлы (реальные MP3 добавятся в Plan 08-02):
- `levl/assets/sounds/.gitkeep`

### 3. Создать папку для Rive ассетов

Анимации Rive хранятся в `assets/animations/` (уже зарегистрирована в pubspec).
Создать подпапку:
```bash
mkdir -p levl/assets/animations/rive
```

### 4. Запустить flutter pub get

```bash
cd levl
flutter pub get
```

## Acceptance Criteria

- `levl/pubspec.yaml` содержит `rive:`, `lottie:`, `just_audio:` без `#` в начале строки
- `levl/pubspec.yaml` содержит `- assets/sounds/` в секции assets
- `flutter pub get` завершается без ошибок
- Папка `levl/assets/sounds/` существует
