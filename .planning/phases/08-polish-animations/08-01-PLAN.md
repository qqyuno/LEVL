# Plan 08-01 — Dependencies Setup

**Phase:** 8 — Polish & Animations
**Wave:** 1
**Depends on:** —
**Goal:** Подключить lottie + just_audio. Rive не используем.

## Steps

### 1. Обновить pubspec.yaml

Раскомментировать lottie, добавить just_audio, убрать rive:

```yaml
  # Animations
  lottie: ^3.1.0

  # Audio
  just_audio: ^0.9.40
```

Строку `# rive: ^0.13.0` — оставить закомментированной (не нужен).

Добавить в секцию `flutter.assets`:
```yaml
    - assets/sounds/
```

### 2. Создать папки

```bash
mkdir -p levl/assets/sounds
mkdir -p levl/assets/animations/lottie
```

### 3. flutter pub get

```bash
cd levl && flutter pub get
```

## Acceptance Criteria

- `pubspec.yaml` содержит `lottie:` и `just_audio:` без `#`
- `pubspec.yaml` содержит `- assets/sounds/` в секции assets
- Папки `assets/sounds/` и `assets/animations/lottie/` существуют
- `flutter pub get` завершается без ошибок
