# Plan 08-03 — Quest Complete: Gold Particle Burst (Lottie)

**Phase:** 8 — Polish & Animations
**Wave:** 2
**Depends on:** 08-01, 08-02
**Goal:** Золотые частицы из кнопки при выполнении задачи + звук + haptic.

## Визуальный результат

При нажатии на кнопку complete:
1. `HapticFeedback.mediumImpact()` — уже есть
2. Lottie burst анимация поверх кнопки (0.8 сек, цвет `#B8962E`)
3. `audioService.playQuestComplete()`
4. Кнопка меняется на золотую галочку (уже работает)

## Files to Read Before Starting

- `levl/lib/features/dashboard/presentation/screens/dashboard_page.dart` — полностью
- `levl/lib/core/theme/app_colors.dart` — цвет gold

## Steps

### 1. Скачать Lottie ассет

Зайти на lottiefiles.com → поиск: `"confetti burst"`, `"sparkle"`, `"particles"`
- Выбрать минималистичный burst без текста и персонажей
- Скачать как JSON → `levl/assets/animations/lottie/quest_complete.json`

Цвет перекрасим программно — скачивай любой золотой или белый burst.

### 2. Конвертировать _QuestCard в StatefulWidget

В `dashboard_page.dart` изменить `_QuestCard extends StatelessWidget` →
`_QuestCard extends StatefulWidget` + `_QuestCardState extends State<_QuestCard>`.

Добавить state:
```dart
bool _showBurst = false;
```

### 3. Добавить Lottie burst в Stack

Обернуть содержимое карточки в `Stack`:

```dart
@override
Widget build(BuildContext context) {
  return Stack(
    clipBehavior: Clip.none,
    children: [
      _buildCard(),         // существующий Container карточки
      if (_showBurst)
        Positioned(
          right: 0,
          top: 0,
          child: IgnorePointer(
            child: SizedBox(
              width: 80,
              height: 80,
              child: Lottie.asset(
                'assets/animations/lottie/quest_complete.json',
                repeat: false,
                delegates: LottieDelegates(
                  values: [
                    // Перекрасить все цвета в gold
                    ValueDelegate.color(
                      const ['**'],
                      value: const Color(0xFFB8962E),
                    ),
                  ],
                ),
                onLoaded: (composition) {
                  Future.delayed(composition.duration, () {
                    if (mounted) setState(() => _showBurst = false);
                  });
                },
              ),
            ),
          ),
        ),
    ],
  );
}
```

### 4. Триггер при complete

Найти GestureDetector кнопки complete. Добавить:

```dart
onTap: () {
  HapticFeedback.mediumImpact();
  setState(() => _showBurst = true);
  ref.read(audioServiceProvider).playQuestComplete();
  onComplete();
},
```

> Чтобы использовать `ref` в StatefulWidget — сделать `_QuestCard` ConsumerStatefulWidget.

### 5. Добавить импорты

```dart
import 'package:lottie/lottie.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:levl/core/audio/audio_service.dart';
```
