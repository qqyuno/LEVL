# Plan 08-03 — Quest Completion Rive Animation

**Phase:** 8 — Polish & Animations
**Wave:** 2
**Depends on:** 08-01
**Goal:** Rive-анимация поверх quest card при выполнении. Минималистичная, в стиле Системы.

## Context

- `rive` подключён после Plan 08-01
- Анимация должна играть один раз при tap на complete, затем исчезать
- Стиль: не праздничный, "зафиксировано" — короткий эффект (частицы/вспышка/чёрточка)
- Ассет: `assets/animations/rive/quest_complete.riv`

## Files to Read Before Starting

- `levl/lib/features/dashboard/presentation/screens/dashboard_page.dart` — полностью, понять структуру QuestCard
- `levl/pubspec.yaml` — убедиться что assets/animations/ зарегистрирован

## Steps

### 1. Получить Rive ассет

Скачать бесплатный минималистичный эффект с https://rive.app/community/ или создать простой:
- Ищи: "confetti minimal", "check mark", "sparkle"
- Стиль: монохром или золото (#B8962E), без цвета
- Сохранить как `levl/assets/animations/rive/quest_complete.riv`

Альтернатива без Rive файла — использовать Flutter-native анимацию в этом плане (AnimationController + ScaleTransition).

### 2. Создать QuestCompleteAnimation виджет

Создать `levl/lib/shared/widgets/quest_complete_animation.dart`:

```dart
import 'package:flutter/material.dart';
import 'package:rive/rive.dart';

class QuestCompleteAnimation extends StatefulWidget {
  final VoidCallback? onComplete;
  const QuestCompleteAnimation({super.key, this.onComplete});

  @override
  State<QuestCompleteAnimation> createState() => _QuestCompleteAnimationState();
}

class _QuestCompleteAnimationState extends State<QuestCompleteAnimation> {
  SMITrigger? _completeTrigger;

  void _onRiveInit(Artboard artboard) {
    final controller = StateMachineController.fromArtboard(artboard, 'State Machine 1');
    if (controller != null) {
      artboard.addController(controller);
      _completeTrigger = controller.findInput<bool>('complete') as SMITrigger?;
      _completeTrigger?.fire();
    }
  }

  @override
  Widget build(BuildContext context) {
    return IgnorePointer(
      child: SizedBox(
        width: 80,
        height: 80,
        child: RiveAnimation.asset(
          'assets/animations/rive/quest_complete.riv',
          onInit: _onRiveInit,
        ),
      ),
    );
  }
}
```

> Если нет .riv файла — заменить на AnimationController + ScaleTransition + FadeTransition (золотая галочка, scale 0→1.2→1, fade out за 600ms).

### 3. Конвертировать _QuestCard в StatefulWidget

В `dashboard_page.dart` изменить `_QuestCard` из `StatelessWidget` в `StatefulWidget`.

Добавить state:
```dart
bool _showAnimation = false;
```

Обернуть карточку в `Stack`:
```dart
Stack(
  clipBehavior: Clip.none,
  children: [
    // Существующий контент карточки
    _buildCardContent(),
    // Анимация поверх
    if (_showAnimation)
      Positioned(
        right: 0,
        top: -20,
        child: QuestCompleteAnimation(
          onComplete: () => setState(() => _showAnimation = false),
        ),
      ),
  ],
)
```

Изменить onTap complete кнопки:
```dart
onTap: () {
  HapticFeedback.mediumImpact();
  setState(() => _showAnimation = true);
  onComplete();
},
```

### 4. Автоматически скрывать анимацию

После завершения Rive анимации (или через таймер 1.5 сек):

```dart
// В initState или при _showAnimation = true
Future.delayed(const Duration(milliseconds: 1500), () {
  if (mounted) setState(() => _showAnimation = false);
});
```
