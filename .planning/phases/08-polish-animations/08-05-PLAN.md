## Steps

### 1. XP Bar — анимированное заполнение

Найти виджет XP bar в dashboard. Заменить статичный `LinearProgressIndicator` или Container на `TweenAnimationBuilder`:

```dart
TweenAnimationBuilder<double>(
  tween: Tween(begin: oldXpFraction, end: newXpFraction),
  duration: const Duration(milliseconds: 600),
  curve: Curves.easeOutCubic,
  builder: (context, value, _) {
    return Stack(
      children: [
        // Фон бара
        Container(
          height: 6,
          decoration: BoxDecoration(
            color: AppColors.divider,
            borderRadius: BorderRadius.circular(3),
          ),
        ),
        // Заполненная часть
        FractionallySizedBox(
          widthFactor: value,
          child: Container(
            height: 6,
            decoration: BoxDecoration(
              color: AppColors.gold,
              borderRadius: BorderRadius.circular(3),
              // Gold shimmer при заполнении
              boxShadow: value > 0.1 ? [
                BoxShadow(
                  color: AppColors.gold.withValues(alpha: 0.4),
                  blurRadius: 6,
                  spreadRadius: 1,
                ),
              ] : null,
            ),
          ),
        ),
      ],
    );
  },
)
```

> `oldXpFraction` и `newXpFraction` = `xp % 100 / 100` (прогресс внутри текущего уровня).

### 2. Streak — пульс при открытии dashboard

Найти streak виджет в dashboard (иконка огня + число дней).

Обернуть иконку в `_PulsingWidget`:

```dart
class _PulsingWidget extends StatefulWidget {
  final Widget child;
  const _PulsingWidget({required this.child});

  @override
  State<_PulsingWidget> createState() => _PulsingWidgetState();
}

class _PulsingWidgetState extends State<_PulsingWidget>
    with SingleTickerProviderStateMixin {
  late final AnimationController _ctrl;
  late final Animation<double> _scale;

  @override
  void initState() {
    super.initState();
    _ctrl = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 400),
    );
    _scale = Tween(begin: 1.0, end: 1.25).animate(
      CurvedAnimation(parent: _ctrl, curve: Curves.easeInOut),
    );
    // 2 пульса при загрузке, небольшая задержка
    Future.delayed(const Duration(milliseconds: 500), () {
      if (mounted) _ctrl.repeat(reverse: true, count: 2);  // 2 раза туда-обратно
    });
  }

  @override
  void dispose() {
    _ctrl.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return ScaleTransition(scale: _scale, child: widget.child);
  }
}
```

Использование:
```dart
_PulsingWidget(
  child: Icon(Icons.local_fire_department, color: AppColors.gold, size: 20),
)
```

> Примечание: `repeat(count: N)` может не поддерживаться в старых версиях Flutter.
> Альтернатива: `_ctrl.forward().then((_) => _ctrl.reverse().then((_) => _ctrl.forward().then((_) => _ctrl.reverse())))`.
