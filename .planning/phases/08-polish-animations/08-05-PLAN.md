## Steps

### 1. Profile build запуск на устройстве

```bash
cd levl
flutter run --profile
```

Открыть DevTools → Performance → Record → прокрутить dashboard → зафиксировать frame times.

### 2. Dashboard scroll audit

Проверить в `dashboard_page.dart`:

**Возможные проблемы и фиксы:**

**Лишние rebuilds провайдеров:**
- Убедиться что `questNotifierProvider` читается через `ref.watch` только в нужном месте
- `QuestCard` виджеты должны получать данные через параметры, не читать провайдеры внутри

**Отсутствие const:**
- Добавить `const` ко всем StatelessWidget без динамического контента
- Пример: `const SizedBox(height: 8)`, `const Divider()`

**withValues(alpha:) в build:**
- `sphereColor.withValues(alpha: 0.12)` вызывается каждый build — вынести в `late final` или `get`

### 3. Character page radar chart audit

Проверить `character_page.dart` и CustomPainter для radar chart:

**Ключевые проверки:**
- CustomPainter имеет правильный `shouldRepaint` — должен возвращать `false` если данные не изменились
- Обернуть RadarChart в `RepaintBoundary`:
  ```dart
  RepaintBoundary(child: StatsRadarChart(...))
  ```

### 4. Список типовых фиксов применить везде

```dart
// 1. RepaintBoundary вокруг анимаций
RepaintBoundary(child: QuestCompleteAnimation())
RepaintBoundary(child: LevelUpOverlay())

// 2. const конструкторы везде где возможно
const SizedBox(width: 14)  // вместо SizedBox(width: 14)

// 3. shouldRepaint в CustomPainter (radar chart)
@override
bool shouldRepaint(covariant _RadarPainter old) =>
  old.stats != stats || old.maxValue != maxValue;
```

### 5. Финальный profile запуск

Повторить замер. Убедиться что frame time < 16ms (60fps) на основных экранах.

## Acceptance Criteria

- `character_page.dart` или файл radar chart CustomPainter содержит корректный `shouldRepaint` (не `return true`)
- `dashboard_page.dart` содержит хотя бы 3 `const` конструктора (добавленных в эту фазу)
- `QuestCompleteAnimation` и `LevelUpOverlay` обёрнуты в `RepaintBoundary`
- `flutter build apk --release` завершается без ошибок
