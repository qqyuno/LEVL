## Steps

### 1. Скачать Lottie ассет

lottiefiles.com → поиск: `"gold rain"`, `"golden confetti"`, `"stars explosion"`
- Полноэкранный эффект, без текста
- Скачать → `levl/assets/animations/lottie/level_up.json`

### 2. Создать LevelUpNotifier

`levl/lib/shared/providers/level_up_provider.dart`:

```dart
import 'package:riverpod_annotation/riverpod_annotation.dart';

part 'level_up_provider.g.dart';

@Riverpod(keepAlive: true)
class LevelUpNotifier extends _$LevelUpNotifier {
  @override
  int? build() => null;  // null = нет активного события

  void trigger(int newLevel) => state = newLevel;
  void dismiss() => state = null;
}
```

### 3. Кодогенерация

```bash
cd levl && dart run build_runner build --delete-conflicting-outputs
```

### 4. Детектировать level-up в quest_provider.dart

В `_addXpToProfile()` добавить после `isar.writeTxn`:

```dart
final oldLevel = profile.level;
profile.xp += xp;
profile.level = (profile.xp ~/ 100) + 1;
// ... существующий код writeTxn ...

if (profile.level > oldLevel) {
  HapticFeedback.heavyImpact();
  ref.read(audioServiceProvider).playLevelUp();
  ref.read(levelUpNotifierProvider.notifier).trigger(profile.level);
}
```

Добавить импорты:
```dart
import 'package:flutter/services.dart';
import 'package:levl/shared/providers/level_up_provider.dart';
import 'package:levl/core/audio/audio_service.dart';
```

### 5. Создать LevelUpOverlay

`levl/lib/shared/widgets/level_up_overlay.dart`:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:google_fonts/google_fonts.dart';
import 'package:lottie/lottie.dart';
import 'package:levl/core/theme/app_colors.dart';
import 'package:levl/shared/providers/level_up_provider.dart';

class LevelUpOverlay extends ConsumerWidget {
  const LevelUpOverlay({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final newLevel = ref.watch(levelUpNotifierProvider);
    if (newLevel == null) return const SizedBox.shrink();

    return GestureDetector(
      onTap: () => ref.read(levelUpNotifierProvider.notifier).dismiss(),
      child: Container(
        color: Colors.black.withValues(alpha: 0.65),
        child: Stack(
          alignment: Alignment.center,
          children: [
            // Gold rain Lottie — полный экран
            Lottie.asset(
              'assets/animations/lottie/level_up.json',
              fit: BoxFit.cover,
              width: double.infinity,
              height: double.infinity,
              repeat: false,
              delegates: LottieDelegates(
                values: [
                  ValueDelegate.color(
                    const ['**'],
                    value: const Color(0xFFB8962E),
                  ),
                ],
              ),
            ),
            // Текст поверх анимации
            Column(
              mainAxisSize: MainAxisSize.min,
              children: [
                Text(
                  'УРОВЕНЬ $newLevel',
                  style: GoogleFonts.dmSerifDisplay(
                    fontSize: 40,
                    color: AppColors.gold,
                    letterSpacing: 6,
                  ),
                ),
                const SizedBox(height: 12),
                Text(
                  'Система зафиксировала.',
                  style: GoogleFonts.dmSans(
                    fontSize: 15,
                    color: Colors.white70,
                    fontStyle: FontStyle.italic,
                  ),
                ),
              ],
            ),
          ],
        ),
      ),
    );
  }
}
```

### 6. Встроить overlay в ShellRoute

В `levl/lib/core/router/app_router.dart` найти ShellRoute builder.
Обернуть `child` в Stack:

```dart
body: Stack(
  children: [
    child,
    const LevelUpOverlay(),
  ],
),
```

Добавить импорт:
```dart
import 'package:levl/shared/widgets/level_up_overlay.dart';
```
