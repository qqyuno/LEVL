### 1. Создать levelUpProvider

Создать `levl/lib/shared/providers/level_up_provider.dart`:

```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:riverpod_annotation/riverpod_annotation.dart';

part 'level_up_provider.g.dart';

/// Хранит номер уровня при level-up событии. null = нет активного события.
@Riverpod(keepAlive: true)
class LevelUpNotifier extends _$LevelUpNotifier {
  @override
  int? build() => null;

  void triggerLevelUp(int newLevel) => state = newLevel;
  void dismiss() => state = null;
}
```

### 3. Детектировать level-up в quest_provider.dart

В методе `_addXpToProfile()` добавить проверку перед записью:

```dart
Future<void> _addXpToProfile(int xp) async {
  final isar = await ref.read(isarProvider.future);
  final profiles = await isar.userProfileLocals.where().build().findAll();
  final profile = profiles.firstOrNull;
  if (profile == null) return;

  final oldLevel = profile.level;          // << сохранить старый уровень
  profile.xp += xp;
  profile.level = (profile.xp ~/ 100) + 1;
  profile.lastActiveDate = DateTime.now();

  await isar.writeTxn(() async {
    await isar.userProfileLocals.put(profile);
  });

  ref.invalidate(userProfileNotifierProvider);

  // << Если уровень вырос — стрелять событие
  if (profile.level > oldLevel) {
    ref.read(levelUpNotifierProvider.notifier).triggerLevelUp(profile.level);
  }
}
```

Добавить импорт в quest_provider.dart:
```dart
import 'package:levl/shared/providers/level_up_provider.dart';
import 'package:levl/core/audio/audio_service.dart';
```

И воспроизвести звук + haptic при level-up:
```dart
if (profile.level > oldLevel) {
  HapticFeedback.heavyImpact();
  ref.read(audioServiceProvider).playLevelUp();
  ref.read(levelUpNotifierProvider.notifier).triggerLevelUp(profile.level);
}
```

### 4. Добавить Lottie ассет

Скачать бесплатный JSON с https://lottiefiles.com/search?q=level+up&category=animations:
- Стиль: минималистичный, золото/монохром, без мультяшных персонажей
- Ключевые слова: "achievement", "badge", "star minimal", "rank up"
- Сохранить как `levl/assets/animations/level_up.json`

### 5. Создать LevelUpOverlay виджет

Создать `levl/lib/shared/widgets/level_up_overlay.dart`:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:lottie/lottie.dart';
import 'package:levl/core/theme/app_colors.dart';
import 'package:levl/shared/providers/level_up_provider.dart';
import 'package:google_fonts/google_fonts.dart';

class LevelUpOverlay extends ConsumerWidget {
  const LevelUpOverlay({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final newLevel = ref.watch(levelUpNotifierProvider);
    if (newLevel == null) return const SizedBox.shrink();

    return GestureDetector(
      onTap: () => ref.read(levelUpNotifierProvider.notifier).dismiss(),
      child: Container(
        color: Colors.black.withValues(alpha: 0.6),
        child: Center(
          child: Column(
            mainAxisSize: MainAxisSize.min,
            children: [
              Lottie.asset(
                'assets/animations/level_up.json',
                width: 200,
                height: 200,
                repeat: false,
                onLoaded: (composition) {
                  Future.delayed(composition.duration, () {
                    ref.read(levelUpNotifierProvider.notifier).dismiss();
                  });
                },
              ),
              const SizedBox(height: 16),
              Text(
                'УРОВЕНЬ $newLevel',
                style: GoogleFonts.dmSerifDisplay(
                  fontSize: 32,
                  color: AppColors.gold,
                  letterSpacing: 4,
                ),
              ),
              const SizedBox(height: 8),
              Text(
                'Система зафиксировала.',
                style: GoogleFonts.dmSans(
                  fontSize: 14,
                  color: Colors.white70,
                  fontStyle: FontStyle.italic,
                ),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
```

### 6. Встроить LevelUpOverlay в app scaffold

В `levl/lib/core/router/app_router.dart` или в корневой Shell виджет — добавить overlay поверх всего приложения.

Найти ShellRoute builder. Обернуть контент в `Stack`:

```dart

  children: [
    child,  // основной контент
```
