## Система генерации заданий

### Философия
- Суперцель — это **линза**, через которую проходят все задания
- Пользователь движется к суперцели, параллельно развивая выбранные сферы
- Нет искусственного разделения — каждое задание служит и сфере, и цели

### Правила генерации (ровно 3 задания в день)

1. **Задание 1** — прямой шаг к суперцели, но оформленный через одну из сфер
2. **Задание 2** — развитие сферы A (по ротации)
3. **Задание 3** — развитие сферы B (по ротации)

Все три написаны с учётом контекста суперцели — пользователь чувствует связь.

### Ротация сфер
- 2 сферы → обе каждый день
- 3 сферы → все 3 каждый день
- 4 сферы → чередуем: день A (1,2,3), день B (1,2,4), день C (1,3,4), день D (2,3,4)
- Сфера суперцели всегда присутствует

### Структура задания от Claude API
```json
{
  "title": "Прочитать 20 страниц книги",
  "description": "Конкретное описание что делать",
  "sphere": "knowledge",
  "isMainGoalTask": true,
  "xpReward": 30,
  "estimatedMinutes": 25,
  "difficulty": "easy",
  "tip": "Короткая подсказка от Системы"
}
```

### Промпт для Claude (логика)
```
Суперцель: [mainGoal]
Сферы и цели: [spheres + sphereGoals]
Контекст: [lifeContext]
Стиль работы: [workStyle]
Время в день: [dailyMinutes] минут
Уровень: [level], Стрик: [streak] дней

Правила:
1. Ровно 3 задания
2. Первое — прямой шаг к суперцели (isMainGoalTask: true), через одну из сфер
3. Остальные — по сферам по ротации
4. Все написаны с учётом суперцели как контекста
5. Суммарное время ≤ dailyMinutes
6. Стиль: короткий, конкретный, без воды
7. tip — голос Системы: курсив, короткий
```

### Кеширование
- Задания генерируются 1 раз в день
- Кеш-ключ: `userId_YYYY-MM-DD`
- Хранится в таблице `quest_cache` в Supabase
- Если кеш есть — Edge Function не вызывается

### Политика проверки заданий v1

Нейросеть предлагает метаданные, но финальный способ проверки всегда определяет
детерминированный `quest_engine`. Это защищает пользователя от невозможных и
противоречивых проверок.

| Тип действия | Примеры | Проверка | Рекомендуемый след |
|--------------|---------|----------|--------------------|
| focus | чтение, учёба, глубокая работа | таймер 5–60 минут | не требуется |
| movement | тренировка, разминка, прогулка | таймер 5–60 минут | не требуется |
| reflection | решение, вывод, план | подтверждение | короткий текст |
| communication | звонок, сообщение, разговор | подтверждение | текст без скриншотов переписки |
| result | прототип, макет, презентация | подтверждение | фото, скрин или ссылка |
| routine | покупка, бронь, уборка | подтверждение | не требуется |

Правила:
- таймер не может быть длиннее задания и ограничен 60 минутами;
- `estimatedMinutes` и `verificationMinutes` — разные значения;
- дополнительный след (текст, ссылка или фото) остаётся необязательным в MVP;
- задания с обязательной геолокацией не генерируются до появления сохранённых мест;
- геолокация и время пребывания будут отдельной политикой следующего этапа;
- новый cache key обязателен при изменении контракта генератора.

## XP система

- Trivial: 10 XP
- Easy: 25 XP
- Medium: 50 XP
- Hard: 100 XP
- Epic: 200 XP
- Уровень = floor(XP / 100) + 1
- Золото ТОЛЬКО для заработанных наград — нельзя купить

## Монетизация — Free / PRO

| | Бесплатно | PRO (подписка) |
|--|-----------|----------------|
| AI модель | Gemini Flash (бесплатный API Google) | Claude Sonnet |
| Заданий в день | 3 | 3 + перегенерация |
| Tip-ы от Системы | базовые | глубже, персональнее |
| AI-ментор (чат) | нет | да |
| Персонаж + кастомизация | полная | полная |
| Экипировка | разблокируется за достижения | разблокируется за достижения |

**Ключевой принцип:** персонаж и экипировка одинаковы для всех — зарабатываются реальными достижениями, нельзя купить. PRO даёт лучший AI, не лучший персонаж.

**Реализация:** Edge Function проверяет `userTier` → вызывает Gemini или Claude. Промпт одинаковый, меняется только API endpoint.

## Технические решения

- Isar не работает на web/Chrome — только Windows desktop и мобильные
- path_provider нужен для Isar директории на десктопе
- OnboardingData — immutable с copyWith (не мутировать напрямую)
- TextEditingController в StepSphereGoals — per-sphere, в StatefulWidget
- JSON строится через dart:convert jsonEncode (не вручную)
- SnackBar: всегда clearSnackBars() перед новым показом
