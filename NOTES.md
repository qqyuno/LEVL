## Персонаж
**Решение:** Leonardo AI генерирует 10-15 полных образов персонажа в разных outfits.
- Не слои PNG — а полные образы (outfit_1.png, outfit_2.png...)
- Remove.bg убирает фон
- В приложении просто переключается Image компонент
- Разблокировка образов = система наград

Стиль: аниме/RPG детализированный (Вариант Б)
Запасной вариант если не выйдет: силуэт/абстрактный (Вариант В)

---

## Система наград
```
Уровни 1-10      → базовые образы персонажа
Уровни 10-30     → эксклюзивные outfits (золотые #B8962E)
Сезонные         → только в этот месяц, никогда больше
Гильдейские      → только если гильдия победила
Скрытые          → никто не знает как получить заранее
Городские        → топ-10 города за неделю
```
**Правило:** ничего нельзя купить. Только заработать.

---

## Механики мотивации
- **Стрик с пламенем** — визуально больно терять
- **Сезоны 30 дней** — уникальная награда, больше никогда не получить (FOMO)
- **Скрытые ачивменты** — неожиданная награда = дофамин
- **Боссы недели** — общий враг для всего города, коллективно выполнить N задач

## Социальный слой (поэтапно)

### MVP Social
- Чат города (Supabase Realtime по городу)
- Топ недели (лидерборд по XP за 7 дней)
- Счётчик активных игроков в городе

### Версия 2
- Карта с анонимными точками активности (react-native-maps)
- Гильдии — группы 5-10 человек с общей целью
- Совместные боссы недели

### Версия 3
- PvP вызовы между игроками
- Реальные ивенты в городах
- Межгородские войны (Москва vs Питер по суммарному XP)
