# Проектный План: Levl — Твоя жизнь как RPG

Этот документ представляет собой исчерпывающий план-проект (Master Plan) для разработки кросс-платформенного мобильного приложения **Levl**. Он предназначен для использования разработчиком (включая AI-ассистентов, таких как Claude Code) в качестве пошагового руководства ("Северной звезды") на всех этапах реализации.

---

## 1. Концепция и Продуктовое Видение (Product Vision)

**Идея:** Levl — это не список задач, а полноценная RPG-игра, где реальная жизнь пользователя является главным квестом. Каждое действие приносит опыт (XP), дни складываются в эпические главы, а рутина превращается в прокачку персонажа.
**Целевая эмоция:** Воодушевление, дофаминовый отклик от прогресса, ощущение «Я становлюсь сильнее с каждым днем». 
**Атмосфера (Вайб):** Темная тема по умолчанию, стилистика осовремененного темного фэнтези (в духе Baldur's Gate 3, но с минималистичным UI), эпические анимации, чувство значимости происходящего.

> [!TIP]
> **Для Разработчика:** При написании UI-кода всегда помни про "juice" (сочность) — каждое подтверждение квеста должно сопровождаться приятной микро-анимацией, тактильным откликом (Haptic Feedback) и звуком. Никаких скучных чекбоксов.

---

## 2. Архитектура и Технологический Стек

Для обеспечения кросс-платформенности, быстрой разработки и работы Offline-first выбран следующий стек:

### Frontend
- **Фреймворк:** Flutter (Dart). Идеален для кастомных интерфейсов с большим количеством кастомных анимаций и кросс-платформерности.
- **State Management:** Riverpod. Обеспечивает строгую типизацию, реактивность и удобную работу с внедрением зависимостей.
- **Локальная БД:** Isar Database или Hive (для быстрого offline-first и хранения состояний характеристик персонажа/квестов без задержек).
- **Анимации:** Rive и Lottie (для level-up эффектов, микро-анимаций UI, анимированных аватаров).

### Backend & Cloud
- **BaaS:** Supabase (PostgreSQL, Auth, Storage) — предпочтительнее за счет мощной работы с реляционными данными (что важно для инвентаря, квестов, связей) и real-time подписок.
- **Offline-Sync:** Custom Repository layer в приложении.

### AI Core
- **Провайдер:** Anthropic Claude API (или OpenAI) интегрированный через Supabase Edge Functions для безопасности ключей.
- **Функция ИИ:** 
  1. Генерация персональных квестов и "Главы жизни" во время онбординга.
  2. Подстройка сложности "на лету" (Adaptive Difficulty).
  3. Чат с ИИ-ментором-нарратором.
  4. Анализ прогресса пользователя (Журнал Героя).

## 3. Каркас Приложения (Core Features & Screens)

### 3.1. Magic Onboarding (Первые 5-7 минут)
- **Скрин 1:** Эпичное интро-видео/анимация (8 сек). Текст: *"Твоя жизнь — это игра. Давай начнём."*
- **Скрин 2:** Создание персонажа (Ввод имени + Выбор или генерация 아ватара).
- **Скрин 3-7:** Интерактивный Health-Bar опрос:
  - Колесо баланса состояния: Здоровье, Карьера, Отношения, Энергия, Финансы, Развитие.
  - Цели (на 3-6 месяцев), уровень энергии, радость/стресс, время на игру, стиль квестов.
- **AI Processing Screen:** Анимация генерации. ИИ выдает стартовый уровень, "Название Главы" (например, "Из Хаоса в Контроль"), план на 90 дней и 3 Main Quests.
- **Скрин Успеха:** Вывод сгенерированного персонажа: *"Добро пожаловать, [Имя]. Твоя легенда начинается здесь."*

### 3.2. Dashboard (Экран Дофамина)
- **Header:** Уровень, Имя Главы, Огонек Стрика (Streak).
- **Hero Сегмент:** Кликабельный Аватар в центре, под ним массивный XP-bar с прогрессом и цифрами.
- **Quest Feed:** Ежедневные квесты (Daily Quests). Карточки с разным цветовым кодированием (цвета стихий/навыков). Главный квест (Main Quest) вынесен в отдельную крупную карточку.
- **Minimap:** Мини-карта жизни (preview Skill Tree внизу экрана).
- **FAB (Floating Action Button):** Кнопка "Поговорить с ИИ-ментором".

### 3.3. Character Sheet (Профиль Героя)
- Полноценный RPG-интерфейс персонажа.
- **Характеристики:** 6 шкал (например: Дисциплина, Знания, Отношения, Энергия, Воля, Мудрость).
- **Экипировка/Внешний вид:** Возможность менять визуальные эффекты или одежду за достижение целей.
- **Текущая Глава:** Описание текущей миссии.
- **Достижения & Лог:** Иконки ачивок, лог полученного опыта и Level-up'ов.

### 3.4. Quest System (Система Квестов)
- **Daily Quests:** 3-5 штук, обновляются каждые 24 часа.
- **Main Quest:** Большая цель (30-90 дней) с этапами.
- **Side Quests:** Доп. задания, сгенерированные ИИ, основанные на пробелах в колесе баланса.
- **Epic Challenges:** Сложные задания раз в неделю с огромной наградойXP/достижениями.
- **Механика выполнения:** Каждое задание имеет: Фэнтези-название, Сложность (1-5 черепов), Награду, Описание важности. Подтверждение выполнения может требовать фото/заметки. После выполнения — анимация и текст от ИИ-ментора.

## 4. Пошаговый План Разработки (Roadmap для Claude Code)

Этот Roadmap должен использоваться ИИ-разработчиком как инструкция для последовательной работы.

### Phase 1: Foundation & Scaffold
1. Инициализировать Flutter проект.
2. Настроить базовую архитектуру файлов (Features/Core/Shared или Clean Architecture).
3. Настроить Riverpod для стейт-менеджмента и подключить GoRouter.
4. Создать базовую дизайн-систему (ThemeData) в концепции Dark Fantasy: цвета `surface`, `primary`, типографика (жирные заголовки, чистые текста), стили кнопок.
5. Интегрировать локальную БД (Isar / Hive) и прописать базовые модели (User, Quest).

### Phase 2: UI Framework & Magic Onboarding
1. Сделать UI-компоненты: ProgressBar, AvatarContainer, QuestCard.
2. Реализовать флоу 7 экранов онбординга с красивыми прогресс-барами.
3. Подключить Supabase API и написать Edge Function для проброса промпта в LLM.
4. Настроить генерацию начального состояния персонажа и сохранить в БД.

### Phase 3: Dashboard & Gamification Engine
1. Реализовать ядро вычисления XP, систему Level-Up'ов и отслеживания стрика (Streak).
2. Сверстать Dashboard со всеми карточками.
3. Реализовать логику добавления, редактирования и "вычеркивания" квеста. Обязательно встроить анимации Rive/Lottie при нажатии "Выполнено".
4. Настроить таймер/cron для обнуления daily квестов.

### Phase 4: Character Sheet & Progression
1. Сверстать экран Character Sheet в RPG-стиле.
2. Привязать выполнение определенных квестов к прокачке 6 характеристик (Skill Tree механика).
3. Реализовать получение локальных "Достижений" при достижении уровней/выполнении серий квестов.

### Phase 5: AI-Mentor & Dynamic Difficulty
1. Сверстать UI чата с ментором.
2. Написать логику отправки контекста (истории выполненных заданий за неделю) ИИ-агенту.
3. Прописать скрипт: ИИ раз в день (или при запуске) анализирует прогресс и выдает пуш: мотивирующий или усложняющий квесты.

### Phase 6: Polish & Social (MVP)
1. Доработка "сочности" интерфейса: Haptic Feedback, звуковые эффекты меню/левелапа.
2. Доработка логики облачной синхронизации Supabase.
3. Функционал MVP социалки: возможность пошерить ссылку на персонажа (Web-вью или диплинк).

---

## 5. Дополнительные требования к коду

1. **Компоненты:** Создавать универсальные компоненты с четким разделением state/UI.
2. **Offline-First:** Любое действие сначала пишется локально и отображается на UI, затем (в фоне) отправляется на сервер для синхронизации.
3. **Комментарии:** Весь код должен быть задокументирован для того, чтобы в нем было легко ориентироваться.
