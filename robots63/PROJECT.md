# ROBOTS63 — Project Brief

## Концепт
Интернет-магазин / витрина роботов с ИИ для рынка СНГ.
Специализация: гуманоидные роботы и робособаки с искусственным интеллектом.

**Домен:** куплен (подключить при деплое на Vercel)
**Tagline:** BUILD THE FUTURE. MOVE IT.

---

## Бренд

- **Логотип:** чёрный минимализм, силуэт гуманоида, капс шрифт
- **Цвета:**
  - Фон: #FFFFFF
  - Текст: #171717
  - Серый: #404040
  - Акцент (золото, только CTA): #A16207
  - Hero фон: #0A0A0A
  - Граница: #E5E5E5
- **Шрифты:**
  - Заголовки: Space Grotesk 500–700
  - Тело / UI: Inter 400–600
  - Цены / характеристики: JetBrains Mono

---

## Референс дизайна

**unitree.com** — за основу берём:
- Fullscreen hero с видео/фото робота
- Продуктовые карточки с оверлеем текста
- Таблица характеристик с тирами цен
- Тёмный футер, мульти-колонки
- Навигация с дропдаунами

---

## Стек

- **Framework:** Next.js 14 (App Router)
- **Стили:** Tailwind CSS
- **Анимации:** Framer Motion
- **Хостинг:** Vercel (бесплатно)
- **Форма заявок:** → email / Telegram

---

## Структура сайта

```
/ — Главная (hero + категории + CTA)
/catalog — Каталог (фильтры: гуманоиды / робособаки / бренд)
/catalog/[slug] — Страница продукта
/about — О компании
/contact — Оставить заявку
```
